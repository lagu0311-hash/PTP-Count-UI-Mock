# PTP Count — 精密レビュー UIモック

**公開用・合成画像専用の独立UI試作品**。完成版PTP Count v1.0とは別リポジトリです。

## 操作
1. privacy確認（演出）にチェック → 「サンプル画像で開始」
2. 架空の8ポケットをタップして人間正解点を追加・修正
3. 正解点を固定（演出）→「合成AI点を表示してレビューへ」
4. ①正解、②重複、③帰属未確定、④検出漏れ、⑤誤検出、⑥判断できない、の各モードで点を選び判定関係を追加・解除
5. 未確認G/Aの表示、完成確認画面を試す

## 安全境界
- 架空画像・架空点のみ。患者画像、教師データ、AIモデル、秘密情報は含めない
- 実AI推論、原画像保存、正解点の永続固定、レビュー保存、JSON書出し、サーバー通信は **未実装**
- リロードで操作状態が消える。完成保存ボタンも画面演出のみ
- 研究評価・臨床利用・職員公開の承認を意味しない
- 完成版PTP Count v1.0のソース・Site・DBには触れない
